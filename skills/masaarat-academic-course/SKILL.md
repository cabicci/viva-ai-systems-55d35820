# Masaarat academic course production

Use the same provenance, localization and media machinery as technical courses, but design evidence for academic learning. The generic package path is smoke-tested; a complete academic curriculum still requires its own pilot.

Read AGENTS instructions, docs/production/README.md, docs/production/ACADEMIC.md and experiments/course-pipeline/README.md. Inspect existing IDs and preserve accepted media. Follow the user's branch, preview and publication boundaries.

## Learning design

Establish audience, prerequisites, source language and exact academic outcomes. Distinguish recall, explanation, application, analysis and evaluation rather than labelling all questions higher-order.

Build a coherent concept sequence. Use worked reasoning with intermediate steps, then guided and independent problems. Include contrasting examples, common misconceptions and explanatory feedback where useful. An essay or case needs evidence criteria and a defensible rubric, not only a multiple-choice score.

Choose assessment that reveals the intended learning. Do not copy machinery-safety checklists into theory or certify mastery from page completion. If the discipline needs laboratories or fieldwork, state supervision and observed evidence separately.

## Shared production

Author complete locale packages with stable semantic IDs, separate display/narration/caption text, localized examples and preserved meanings, units and citations. Configure only requested course languages; do not alter platform language policy.

The shared engine accepts --package <directory>, derives scene and locale counts from the manifest, and supports mode: academic without requiring a vocational checklist. Voice styles currently cover Egyptian Arabic, English, Italian and German. Add and review any other language explicitly.

Run validation and a dry plan before a bounded request for authorized scope. The soil workflow is only an example; create a separately scoped workflow for an academic pilot. Extend visual compositions for the subject instead of renaming soil diagrams.

Reuse speech by its content/voice/model key and preserve partial work. Verify timing and rendered media. Distinguish generation, language review, subject review and owner acceptance. Temporary Actions artifacts are not a permanent archive.

Where the owner requests generated 3D-style infographics, use the shared Gemini image stage under Actions. Keep localized text and exact numeric labels in Remotion, and preserve image and speech caches separately. A technical course's five visual subjects are not reusable academic content.

Before generating the batch, define explicit visual and subject-accuracy criteria. Inspect outputs automatically against that contract, bound corrective attempts and report unresolved exceptions. Do not require manual approval for every image; the reviewable complete pilot remains the intended owner checkpoint.

## Evidence and handoff

Explain the design with named references and actual applications. The example uses FAO e-learning design, IES worked examples/retrieval/spacing, and CAST UDL; judge applicability and evidence strength for new learners and disciplines. Do not claim endorsement or accreditation.

Show a reviewable pilot before bulk production when required. Integrate authenticated assistant, storage, indexing or deployment only within authorized scope and through the existing project. Never call a static reference guide a live AI assistant.

Report completed outputs, checks, unresolved claims and remaining decisions. Preserve accepted course IDs, Bunny media and source history.
