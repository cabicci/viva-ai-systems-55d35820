# نقل صور الدروس (400 PNG) إلى CDN بدل المشروع

## الوضع الحالي
- 400 صورة بحجم ~102 ميجا في `src/assets/lesson-visuals/controlled-v1/`.
- سكربت `controlled-visuals:materialize-runtime-assets` يعيد كتابة الـ400 ملف قبل كل إقلاع للسيرفر.
- `controlledV1BrowserResolver.ts` يستخدم `import.meta.glob` بـ `eager: true` على الـ400 أصل، فالمتصفح في التطوير يطلب مئات الموديولات في أول تحميل.

هذا هو سبب بطء أول دخول للبريفيو. نقل الصور لـ CDN يحل الجزء الأكبر منه.

## الخطة

### 1. اختيار مكان الاستضافة
- **Bunny Storage/CDN**: يحتاج Storage Zone + مفتاح `BUNNY_STORAGE_API_KEY` (مفتاح الفيديو الحالي لا يصلح للتخزين). يُضاف كسر (secret) قبل البدء.
- **بديل جاهز الآن بدون أي مفاتيح**: Lovable Assets CDN — رفع بأمر واحد لكل ملف وإرجاع رابط ثابت `/__l5e/assets-v1/...`.

النتيجة النهائية واحدة: كل صورة تصبح رابط CDN مطلق بدل ملف داخل المشروع.

### 2. الرفع وبناء خريطة الروابط
- رفع الـ400 صورة دفعة واحدة بسكربت.
- توليد `controlledV1BrowserManifest.json` محدّث يحمل حقل `url` لكل خلية (بجانب `assetKey` و`acceptedSha256` الحاليين).
- التحقق: 400 رابط، صفر مفقود، تطابق SHA-256 مع المانيفست الحالي.

### 3. تعديل الـ Resolver
- حذف `import.meta.glob` الـ eager بالكامل.
- `resolve()` يقرأ الـ URL مباشرة من المانيفست.
- الحفاظ على نفس واجهة `ControlledV1ResolveResult` حتى لا تتغير أي مكوّنات تستهلكها.

### 4. إيقاف مُوَلِّد الأصول
- إزالة `materialize-runtime-assets` من خطوة ما قبل التشغيل/البناء (يبقى السكربت موجودًا للاستخدام اليدوي).
- حذف `src/assets/lesson-visuals/controlled-v1/` من المشروع (~102 ميجا) بعد نجاح البناء.

### 5. التحقق
- `bun run build` يمر.
- فحص عيّنة دروس في البريفيو: الصور تظهر من CDN، وزمن أول تحميل بعد إعادة التشغيل يُقاس ويُقارن بالحالي.

## ملاحظات تقنية
- الصور تُقدَّم بكاش CDN طويل الأمد، فلا مشكلة من عدم تغيّر الروابط لأن كل أصل يأخذ معرّفًا فريدًا.
- سير عمل GitHub الخاص بإنتاج الصور يبقى كما هو؛ فقط خطوة النشر النهائية تصبح "ارفع إلى CDN وحدّث المانيفست" بدل "اكتب داخل المشروع".
- لا تغيير في قاعدة البيانات ولا في الفيديوهات (Bunny Stream يبقى كما هو).

## سؤال واحد قبل التنفيذ
هل نستخدم Bunny Storage (يتطلب منك إنشاء Storage Zone ومفتاحه) أم Lovable Assets CDN (يبدأ فورًا بدون مفاتيح)؟
