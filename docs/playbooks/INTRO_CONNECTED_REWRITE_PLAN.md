# Intro Connected Rewrite Plan

## Purpose

This document plans the rewrite of Intro L2–L7 as one connected beginner journey — not as isolated lesson edits.

Implementation may happen in batches, but the curriculum logic must be planned across the full Intro path first.

**Governing context:** Curriculum architecture is frozen at 100 lessons. Intro stays at 7 lessons. L1 is already piloted. L2–L7 still use the old v2 stack and need a connected rewrite aligned with pilot standards.

**Status:** Planning only — no lesson file edits in this step.

---

## 1. Purpose

The purpose of this plan is to rewrite Intro L2–L7 as one connected beginner journey, not as isolated lesson edits.

Implementation may happen in batches, but the curriculum logic must be planned across the full Intro path first.

---

## 2. Fixed Decisions

- Intro remains 7 lessons.
- Existing Intro slugs stay unchanged.
- Intro L1 is treated as the pilot/reference.
- L2–L7 should be rewritten to match the pilot learning experience.
- Missions are practice, not exams.
- Progress should feel unlocked by meaningful attempt, not perfect score.
- No mass route/slug changes.
- No new Intro lessons should be added unless a blocker is found.

---

## 3. Intro Journey Arc

The Intro path should move the learner through this emotional and practical journey:

1. “AI is not magic; it is a practical helper.”
2. “I can ask it better questions.”
3. “I can open a tool and try safely.”
4. “I know what AI can and cannot do.”
5. “I know when to use AI vs normal software.”
6. “I am not too late or too technical to learn this.”
7. “I can choose the path that matches my real goal.”

---

## 4. Lesson-by-Lesson Target Map

### L1 — `intro-m1-l1-what-is-ai`

**Status:** Already piloted.

**Role in journey:** Introduce AI as a practical helper and reduce fear.

**Main Aha:** AI is a tool you try, not a mystery you must understand fully before starting.

**Action:** Monitor only. No rewrite now unless later copy polish is needed.

---

### L2 — `intro-m1-l2-first-prompt`

**Role in journey:** Teach the learner that AI output changes when the question becomes clearer.

**Target Main Aha:** A good prompt is not a magic sentence; it is clear instructions with context.

**Target content:** Replace the old glossary-first structure with:

- Hero / orientation
- Familiar bad prompt moment
- Core idea: role + context + task + format
- Simple example
- Limited glossary only after core idea
- Light check
- Practice mission

**Mission target:** Learner writes one simple improved prompt for a real personal/work use case.

**Mission type:** Practice Mission.

**Risk:** Do not make prompt engineering feel technical or advanced.

---

### L3 — `intro-m1-l3-setup-your-ai`

**Role in journey:** Move the learner from watching to trying.

**Target Main Aha:** The first win is opening one AI tool and sending one safe message.

**Target content:**

- Focus on safe setup and first interaction.
- Avoid platform promotion.
- Avoid “ممنوع” language.
- Explain that the exact AI tool is less important than trying.

**Mission target:** Learner opens one AI tool and sends a simple starter prompt.

**Mission type:** Practice Mission.

**Risk:** Do not assume paid accounts, API keys, or technical setup.

---

### L4 — `intro-m1-l4-ai-can-cannot`

**Role in journey:** Set trust boundaries before deeper use.

**Target Main Aha:** AI is useful, but it can be wrong; smart users verify important outputs.

**Target content:** Teach:

- AI is good at drafting, summarizing, brainstorming, explaining
- AI is risky with facts, legal/medical/financial certainty, current events, private data
- Verification is part of using AI, not proof that AI failed

**Mission target:** Learner classifies 3 use cases into:

- Good for AI
- Use with checking
- Avoid / ask a human

**Mission type:** Quick Check or Practice Mission.

**Risk:** Avoid scaring the learner away from AI.

---

### L5 — `intro-m1-l5-ai-vs-software`

**Role in journey:** Help the learner choose the right tool.

**Target Main Aha:** Use software when the process is fixed; use AI when the task needs language, judgment, or variation.

**Target content:** Compare:

- Calculator / spreadsheet / CRM / calendar = fixed tools
- AI = flexible thinking/writing/helper layer
- Best result often comes from using both together

**Mission target:** Learner picks 3 tasks from their life/work and chooses:

- AI
- Software
- Both

**Mission type:** Practice Mission.

**Risk:** Do not turn this into a technical software architecture lesson.

---

### L6 — `intro-m1-l6-learn-without-fear`

**Role in journey:** Remove emotional resistance before path selection.

**Target Main Aha:** You do not need to be technical; you need to keep making small useful attempts.

**Target content:** Address:

- fear of being late
- fear of not being technical
- fear of “everyone understands except me”
- learning by small tries

**Mission target:** Learner writes their personal “small next step” and one fear that will not stop them.

**Mission type:** Reflection / Practice Mission.

**Risk:** Avoid motivational fluff. Keep it practical.

---

### L7 — `intro-m1-l7-choose-your-path`

**Role in journey:** Turn the Intro into a confident path decision.

**Target Main Aha:** Choose a path based on the problem you want to solve, not based on which path sounds impressive.

**Target content:** Explain the 3-level structure:

**Stage 00:**

- Intro

**Level 1 — AI User:**

- Business
- Creator
- Analyst

**Level 2 — AI Operator:**

- Automator

**Level 3 — AI Builder:**

- Builder

Explain:

- Business = run better with AI
- Creator = create content and audience with AI
- Analyst = make better decisions with numbers and AI
- Automator = make repeated work run by itself
- Builder = build AI-powered tools/apps

**Mission target:** Learner chooses one path and explains why in 2–3 sentences based on a real goal.

**Mission type:** Capstone / Path Choice Mission.

**Risk:** Do not oversell Builder as the main promise. Builder must feel optional depth, not the default “real” track.

---

## 5. Shared Rewrite Rules for L2–L7

Each rewritten lesson should usually include:

1. Hero / Orientation
2. Tension / familiar problem
3. Core idea before glossary
4. Simple example
5. Limited terms
6. One visual support if useful
7. Video as support, not replacement
8. Light quiz/check
9. Mission near the end
10. Confidence close

### Rules

- One main Aha per lesson.
- No glossary-first structure.
- No English UI labels like TENSION / Quick Win / Failure × Right / Mission in learner-facing headings.
- No visible markdown markers like `**`.
- No harsh language like “ممنوع”.
- No platform promo after mission.
- No 3-question heavy quiz by default.
- Mission must include starter template where useful.
- Confidence close is required for L2–L7.

---

## 6. Intro Term Policy

Allowed English terms, but first use must be explained simply in Arabic.

**Expected terms:**

- AI
- Prompt
- Context
- Model
- Software
- Verification
- Path
- Automator
- Builder
- Analyst
- Creator

Keep terms light. Do not overload any Intro lesson with more than 2–3 new terms unless unavoidable.

---

## 7. Visual and Video Policy

Visuals should explain the idea, not promote the platform.

### Avoid

- screenshots that mainly advertise dashboard/curriculum/assistant
- platform case studies after mission
- visuals that introduce new concepts too late

### Video

- Keep video as optional support.
- Lesson must still work if video is skipped or missing.
- Add skip-friendly caption where appropriate.

---

## 8. Mission Policy

Missions should feel like guided practice.

### Do

- use warm wording
- provide starter templates
- accept imperfect answers
- focus on meaningful attempt
- keep rubric hidden/soft in learner tone

### Avoid

- exam feeling
- score pressure
- harsh pass/fail language
- strict “perfect answer” requirements
- auto-pass through model answer

---

## 9. Implementation Recommendation

Do not implement all six rewritten lessons blindly.

### Recommended implementation order after this plan is approved

**Wave 1:**

- L2 `first-prompt`
- L3 `setup-your-ai`

**Wave 2:**

- L4 `ai-can-cannot`
- L5 `ai-vs-software`

**Wave 3:**

- L6 `learn-without-fear`
- L7 `choose-your-path`

### Before implementation

- produce connected draft content for L2–L7 together
- review continuity
- only then convert to lesson files in controlled waves
