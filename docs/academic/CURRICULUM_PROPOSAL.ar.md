## الوحدة 1: أساسيات عالم الأعمال
**ناتج التعلم:** يحلل المتعلم منشأة بسيطة ويربط العميل والقيمة والموارد والإيرادات وأصحاب المصلحة.
**المخرج:** خريطة منشأة وصفحة تعريف بالمشكلة والعميل.
1. كيف تعمل المنشأة وتصنع قيمة للعميل؟ — `AC-BUS-M01-L01`
2. وظائف المنشأة وترابط قراراتها — `AC-BUS-M01-L02`
3. بيئة الأعمال وأصحاب المصلحة وأخلاقيات القرار — `AC-BUS-M01-L03`

## الوحدة 2: صفات القائد وقدراته
**ناتج التعلم:** يبرر قرارًا قياديًا ويصمم توزيعًا واضحًا للمسؤوليات ومحادثة تغذية راجعة.
**المخرج:** مصفوفة مسؤوليات وتحليل موقف قيادي.
1. القيادة والإدارة والمسؤولية — `AC-BUS-M02-L01`
2. اتخاذ القرار وحل المشكلات — `AC-BUS-M02-L02`
3. التواصل والتفويض والتغذية الراجعة — `AC-BUS-M02-L03`
4. بناء الفريق والتحفيز وإدارة الخلاف — `AC-BUS-M02-L04`

## الوحدة 3: الأعمال الصغيرة وكيفية بنائها
**ناتج التعلم:** يصمم نموذج أعمال أوليًا ويربط افتراضاته بأدلة قابلة للجمع.
**المخرج:** نموذج أعمال وسجل افتراضات وخطة بحث عميل.
1. اختيار مشكلة وشريحة عملاء محددة — `AC-BUS-M03-L01`
2. بحث العميل وصياغة أسئلة المقابلات — `AC-BUS-M03-L02`
3. عرض القيمة ونموذج الأعمال — `AC-BUS-M03-L03`
4. قنوات الوصول والبيع وتجربة العميل — `AC-BUS-M03-L04`

## الوحدة 4: توليد الأفكار المبتكرة ودراسة جدواها
**ناتج التعلم:** يقارن بدائل ويحسب سيناريو جدوى مبسطًا ويبرر قرار الاستمرار أو التعديل.
**المخرج:** دراسة جدوى تعليمية مع افتراضات وسيناريوهات موثقة.
1. توليد الأفكار واختيارها بمعايير واضحة — `AC-BUS-M04-L01`
2. تحليل السوق والبدائل والمنافسة — `AC-BUS-M04-L02`
3. الجدوى التشغيلية والموارد والطاقة — `AC-BUS-M04-L03`
4. التكاليف والإيرادات والتعادل والتدفق النقدي — `AC-BUS-M04-L04`
5. اختبار الفكرة وتحليل السيناريوهات وقرار الاستمرار — `AC-BUS-M04-L05`

## الوحدة 5: التخطيط الاستراتيجي وإعداد خطة العمل
**ناتج التعلم:** يحول نتائج الدراسة إلى أهداف وخطة موارد وتشغيل ومؤشرات قابلة للمتابعة.
**المخرج:** مسودة خطة عمل متكاملة.
1. الرؤية والرسالة والأهداف القابلة للقياس — `AC-BUS-M05-L01`
2. تحليل البيئة والقدرات واختيار الأولويات — `AC-BUS-M05-L02`

4. خطة التشغيل والموارد والميزانية — `AC-BUS-M05-L04`
5. كتابة خطة عمل مترابطة ومؤشرات متابعة — `AC-BUS-M05-L05`

## الوحدة 6: تأسيس المشروع وتجهيزه للتشغيل
**ناتج التعلم:** يصمم قائمة جاهزية وخريطة إجراءات ويحدد ما يحتاج تحققًا رسميًا في بلد المشروع.
**المخرج:** قائمة جاهزية وخطة تشغيل تجريبي ومصادر تحقق محلية.
1. متطلبات التأسيس وخريطة التحقق المحلية — `AC-BUS-M06-L01`

4. الأدوات الرقمية وتجربة التشغيل والاستعداد للإطلاق — `AC-BUS-M06-L04`

## الوحدة 7: إدارة المشروع باحترافية
**ناتج التعلم:** يدمج مخرجات الوحدات في خطة قابلة للتنفيذ ويدافع عن قراراتها ويحدد حدود أدلتها.
**المخرج:** ملف نهائي: خطة عمل وجدول ومخاطر ومؤشرات ومراجعة ذاتية.
1. نطاق المشروع ومخرجاته وتقسيم العمل — `AC-BUS-M07-L01`
2. الجدول والموارد والتكلفة والاعتماديات — `AC-BUS-M07-L02`
