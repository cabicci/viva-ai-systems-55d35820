## Chunk Contract

### Identifier format

```
{locale}/{lessonId}/s{sectionIndex}/c{chunkIndex}
```

### Content types

`explanation`, `glossary`, `quiz`, `mission`, `example`, `summary`, `other`

### Indexed fields

- Section role, heading, subtitle
- `contentMarkdown`, bullets, tables
- Quiz question/options/explanation (not `correctIndex`)
- Mission intro/delivery/rubric (not `yamlIntent`/`yamlType`)

### Excluded fields

- `sourceFile`, `generatedAt`
- `yamlIntent`, `yamlType`
- `correctIndex` (quiz answer key)
- Internal structural noise

### Chunking parameters

- Max chars: 1200
- Overlap: 100
- Min report threshold: 20 chars
- Soft max report threshold: 2000 chars

## Manifest Schemas

### Package manifest (`package-manifest-v1`)

Tracks 300 packages with checksums and chunk counts per package.

### Chunk manifest (`chunk-manifest-v1`)

Tracks all chunks with stable IDs, text checksums, locale counts, and embedding model placeholder metadata.

### Index version (`rag-index-v1`)

Binds manifests to Content Freeze SHA for reproducible regeneration.

## Locale Isolation Contract

- Chunks never mix locales
- Chunks never mix lessons
- Retrieval filters must include `locale` parameter
- Per-locale reports in reindex planning

## Retrieval Filter Contract

Future vector search must filter by:

- `locale` (required)
- `lesson_id` (optional, for in-lesson context)
- `path_id` / `module_id` (optional scope)
- `min_similarity` threshold

## Citation Source Contract

Citations must reference:

- `lessonId`, `locale`, `sectionRole`, `sectionHeading`
- `productionRoute` when available
- `chunkId` for traceability

## Reindex Lifecycle

1. **Discover** approved packages
2. **Verify** corpus (300 count, AG4 records, exclusions)
3. **Generate** deterministic chunks
4. **Build** package + chunk manifests
5. **Diff** against previous manifests
6. **Plan** skip / reindex / delete / retry actions
7. **Stage** new index (future: `knowledge_chunks_staging`)
8. **Activate** staging index (requires Launch approval)
9. **Rollback** to previous manifest checksum set

### Retry-only-failed

When `retryOnlyFailed=true`, only packages in `failedUnits` list are reindexed; all others are skipped.

### Checksum-based skipping

Unchanged `packageChecksum` → skip embedding regeneration for that package.

## Paid Execution Approval Gate

**This phase makes zero paid API calls.**

Embedding execution requires separate approval:

- Model: `text-embedding-3-small` (1536 dimensions)
- Estimated batches derived from chunk manifest
- Execution via `assistant-seed.functions.ts` or dedicated indexer
- Cost estimate produced from chunk count before execution
