---
name: Lesson naming convention
description: Always refer to lessons by path + module + lesson number alongside the id
type: preference
---
When mentioning any lesson, always use: "[المسار] M[رقم الموديول] · الدرس [رقم] — [lesson-id]".
Example: "Builder M8 · الدرس 22 — builder-m8-tables-columns".
Never mention a lesson id alone without its path name, module number, and lesson number.
