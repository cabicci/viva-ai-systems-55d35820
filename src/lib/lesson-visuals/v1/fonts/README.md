# Tajawal (lesson-visuals v1)

Bundled font files for lesson visual rendering and validation. **Validators MUST load and use only these Tajawal files — never Segoe UI, system UI fonts, or other substitutes.**

## Files present

| File | Weight | Format | Notes |
|------|--------|--------|-------|
| `Tajawal-Regular.ttf` | 400 (Regular) | TrueType | Full font from Google Fonts OFL repository |
| `Tajawal-Bold.ttf` | 700 (Bold) | TrueType | Full font from Google Fonts OFL repository |
| `Tajawal-Regular.woff2` | 400 (Regular) | WOFF2 | Arabic subset, Google Fonts CDN (`fonts.gstatic.com`, v12) |
| `Tajawal-Bold.woff2` | 700 (Bold) | WOFF2 | Arabic subset, Google Fonts CDN (`fonts.gstatic.com`, v12) |

## Source

- **Family:** [Tajawal](https://fonts.google.com/specimen/Tajawal) by Boutros Fonts
- **TTF:** [google/fonts](https://github.com/google/fonts/tree/main/ofl/tajawal) (`ofl/tajawal/`)
- **WOFF2:** [fonts.gstatic.com](https://fonts.gstatic.com/) (served via Google Fonts CSS API)
